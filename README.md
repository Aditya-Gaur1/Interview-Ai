# 🤖 Interview AI

An AI-powered interview preparation platform built with the MERN stack. Users can upload their resume, provide a target job role, job description, and self-description, and receive a personalized interview preparation report generated using AI.

## 🚀 Live Demo
https://interview-ai-1-t2zw.onrender.com


## ✨ Features

- 🔐 Email & Password Authentication
- 🔑 JWT Authentication using HTTP-only cookies
- 🔵 Google OAuth Authentication
- 📄 Resume PDF Upload & Text Extraction
- 🤖 AI-powered Interview Report Generation
- 🎯 Job Role & Job Description Based Preparation
- 🧠 Personalized Technical Interview Questions
- 📊 Interview Preparation Analysis
- 💾 Store Interview Reports in MongoDB
- 📚 View Previous Interview Reports
- 🗑️ Delete Interview Reports
- 🌐 Production Deployment with Render
- 🔒 Secure Cross-Origin Authentication
